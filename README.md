# Real-Time Seller Inventory & CDC Streaming Engine

An end-to-end Change Data Capture (CDC) streaming pipeline that generates real-time e-commerce inventory events, streams them into AWS S3, and auto-ingests them into Snowflake via Snowpipe, Streams, and Tasks using a Medallion Lakehouse Architecture (Bronze -> Silver -> Gold).

---

## 🏗️ Architecture Overview

1. **Producer:** Python script utilizing oto3 and aker streams JSON inventory events (INSERT, UPDATE, DELETE) to Amazon S3.
2. **Ingestion:** S3 Event Notifications trigger Snowflake **Snowpipe** via SQS to auto-ingest incoming raw JSON files into a **Bronze** stage (RAW_INVENTORY_CDC).
3. **Cleansing & Deduplication:** A Snowflake **Stream** captures raw landing data, and a **Task** executes a MERGE query using window functions (ROW_NUMBER()) to update or soft-delete records in the **Silver** relational table.
4. **Analytics & Aggregation:** A second **Stream** feeds a downstream **Gold Task** that computes real-time stock levels, category metrics, and seller analytics for reporting.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x (oto3, aker)
* **Cloud Storage:** AWS S3, AWS SQS, AWS IAM
* **Data Warehouse & Orchestration:** Snowflake (Snowpipe, Streams, Tasks, Storage Integration)
* **Design Pattern:** Change Data Capture (CDC), Medallion Architecture (Bronze, Silver, Gold)

## 🚀 Setup & Execution Instructions

### 1. AWS & Snowflake Integration
1. Execute \snowflake/01_bronze_setup.sql\ to initialize \INVENTORY_CDC_DB\, the Bronze table, and Storage Integration.
2. Update the AWS IAM Role (\SnowflakeS3CDCRole\) trust policy using the \STORAGE_AWS_IAM_USER_ARN\ and \STORAGE_AWS_EXTERNAL_ID\ generated by Snowflake.
3. Configure S3 Event Notifications to route \s3:ObjectCreated:*\ events to the Snowpipe SQS queue ARN (\SHOW PIPES\).

### 2. Stream Data Generation
\\\ash
cd src
pip install -r requirements.txt
python cdc_generator.py
\\\

### 3. Pipeline Transformations
1. Execute \snowflake/02_silver_transformation.sql\ to establish the Silver table, Stream, and automated \MERGE\ task.
2. Execute \snowflake/03_gold_aggregation.sql\ to configure the Gold analytical table and task chain.
